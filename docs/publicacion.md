# Alojamiento y publicación

La aplicación se publicará en un servidor cuando el primer alcance esté definido y listo.

- No asumir que ya existe dominio, servidor o proveedor contratado.
- Recomendar una opción segura, asequible y sencilla de mantener, comparando costes recurrentes y limitaciones antes de configurarla.
- Guiar al usuario paso a paso por la cuenta del proveedor, despliegue, dominio, HTTPS, base de datos, variables de entorno, primer administrador, copias de seguridad y actualizaciones.
- Indicar claramente qué información debe aportar el usuario y cuándo una acción debe realizarla en su propia cuenta.
- No pedir ni copiar contraseñas, claves API o secretos en el chat ni en Git. Explicar dónde introducirlos de forma segura.
- Antes de poner datos reales, explicar cómo verificar que se puede iniciar sesión, que la aprobación funciona, que los permisos se respetan y que los datos pueden restaurarse desde una copia.
- Preparar un procedimiento sencillo de actualización y recuperación ante errores.
